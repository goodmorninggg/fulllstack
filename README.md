BrightBits - AI-Powered Blog Application

BrightBits is a full-stack MERN (MongoDB, Express, React, Node.js) blogging platform that integrates AI content generation. It features a public-facing blog site and a comprehensive admin dashboard for managing posts and comments.

🚀 Features

User Features

-Browse Blogs: View a list of published blog posts.

-Read Blogs: Read detailed blog content with rich text formatting.

-Search & Filter: Search for blogs by title or category.

-Comments: Users can add comments to blog posts (subject to admin approval).

Admin Features

-Secure Login: JWT-based authentication for administrators.

-Dashboard: Overview of key metrics (Total Blogs, Comments, Drafts, Recent Activity).

Blog Management:

-Create new blogs with a rich text editor (Quill).

-AI Content Generation: Generate blog content automatically using an AI prompt (integrated with Google Gemini).

-Edit and delete blog posts.

-Toggle publish status (Draft/Published).

-Image uploads handled via ImageKit for optimization.

-Comment Management: View, approve, or delete user comments.

🛠️ Tech Stack

Frontend:

-React.js

-Tailwind CSS (Styling)

-Context API (State Management)

-Axios (API Requests)

-React Router DOM (Navigation)

-React Toastify (Notifications)

-React Quill (Rich Text Editor)

Backend:

-Node.js & Express.js

-MongoDB & Mongoose (Database)

-JSON Web Token (JWT) (Authentication)

-Multer (File Handling)

-ImageKit (Image Storage & Optimization)

-Google Gemini API (AI Content Generation)
